# Brainlume Interactive Mobile Prototype V1

Interactive mobile simulation based on the approved Direction B / WHOOP-referenced UI system.

## Open

- Default experience: `index.html`
- Direct screen: `index.html?screen=S02`
- All-screen gallery: `index.html?gallery=1`

The folder can be uploaded directly to a GitHub Pages repository.

## Core demo flow

1. Home → Brain Check
2. Introduction → Fit & signal check
3. Three-channel EEG collection
4. Result generation → Check Result
5. Start Light Session
6. Near-infrared session → After EEG
7. Before / After animated brain-map result

## Demo timing

- Brain Check collection: approximately 5 seconds.
- Before EEG: approximately 5 seconds.
- Near-infrared light session: approximately 5 seconds.
- After EEG: approximately 5 seconds.
- Result generation: approximately 1 second.

The screen copy preserves the intended real-world task duration, while the interactive demo advances at an accelerated rate.

## Interactive details

- Three independent EEG channels: FP1, FPZ and FP2.
- Different live frequencies, amplitudes and simulated contact quality per channel.
- Pause, disconnect and reconnect states.
- Animated progress rings, timers, progress bars and stage transitions.
- Animated Before / After brain energy maps.
- Bottom navigation, history records, filters and permission toggles.
- Reduced-motion accessibility support.

## Product and interpretation boundary

- Device imagery uses the supplied real Brainlume product photograph.
- Brain maps and EEG signals are demonstration visualizations, not medical diagnostic output.
